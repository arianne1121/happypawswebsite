# Happy Paws Veterinary Clinic: Website Concept

A responsive website concept for a fictional veterinary clinic, built as a portfolio project.

**Live site:** https://happypawswebsite.vercel.app

> **Note:** Happy Paws Veterinary Clinic is a made-up business. All names, text, contact details, and testimonials are placeholders created for demonstration purposes.

## Features

- **Responsive design** that works on desktop, tablet, and mobile
- **Sticky navigation** with a Services dropdown (hover on desktop, tap on mobile)
- **Home page** with hero, about the clinic, why choose us, services overview, gallery, testimonials, hours and location, and a closing call to action
- **Dedicated Services page** covering six services: wellness exams, vaccinations, dental care, surgery, emergency care, and grooming
- **Appointment request form** that pre-selects the service when you click "Book" on a service
- Clean, friendly look with a teal and white palette and a warm accent color

## Built With

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)
- Photos from [Unsplash](https://unsplash.com)
- Built with the help of [Claude Code](https://claude.com/claude-code)
- Hosted on [Vercel](https://vercel.com), with code stored on GitHub

## Project Structure

```
├── index.html      # Home page
├── services.html   # Services page
├── style.css       # Styles and layout
├── script.js       # Navigation dropdown, form behavior
└── images/         # Photos used across the site
```

## Run It Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build step is needed.

## Deployment

The site is deployed with Vercel. Pushing changes to the `main` branch on GitHub automatically publishes a new version.
